# Installation

This page covers the common installation paths for FlowGym.

## Install the package

To install the package using [uv](https://docs.astral.sh/uv/):

```bash
uv add flow-gym-suite
```

With `pip` instead:

```bash
pip install flow-gym-suite
```

## Version requirements

The current package metadata requires Python 3.10+.
